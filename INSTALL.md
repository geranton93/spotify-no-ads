# Install guide

The step-by-step guide for people who do **not** write code is now the main part of the
[README](README.md#install-no-coding-needed). It covers the whole path:

- what Spicetify is and why it is needed at all;
- **Step 1** — install Spicetify (macOS, Windows, Linux) and check it worked;
- **Step 2** — install this add-on with one pasted line, plus the manual three-command path if the
  script refuses to run;
- **Step 3** — check that the ads are really gone (including a 10-second exact check, not just
  listening);
- what to do after a Spotify update;
- troubleshooting, how to remove everything, and the honest notes (no account is touched, no paid
  features, possible conflict with Spotify's Terms of Service).

This file exists so that links from older releases, the installer's own "something went wrong" message,
and other projects keep working. Deeper material lives in:

| Re-installing and rolling back after an update | [`docs/maintenance.md`](docs/maintenance.md) |
| The one-line installers themselves | [`install.sh`](install.sh) / [`install.ps1`](install.ps1) |
